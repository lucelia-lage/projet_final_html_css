JavaScript : Langage de programmation pour le Web

JavaScript est un langage de programmation utilisé pour rendre les pages web interactives. Grâce à JavaScript, vous pouvez manipuler le contenu de la page, gérer des événements utilisateur et créer des animations, des jeux, et bien plus encore.

La syntaxe de JavaScript

JavaScript suit une syntaxe de programmation de base composée de :

  • Variables : Elles stockent des valeurs et peuvent être déclarées avec let, const, ou var.
  • Fonctions : Elles regroupent des instructions exécutées à la demande, définies avec le mot-clé function.
  • Événements : Ils sont utilisés pour interagir avec l'utilisateur, comme onclick, onload, etc.

Exemple de code JavaScript

Voici un exemple simple de fonction JavaScript qui affiche un message :

function afficherMessage() { alert("Bienvenue sur notre site !"); }

Cette fonction affiche une alerte lorsque l'on l'appelle, par exemple avec un événement onclick.

Interaction avec HTML

JavaScript peut manipuler les éléments HTML en utilisant le DOM (Document Object Model). Voici un exemple pour changer le contenu d'un élément HTML :

document.getElementById ("monElement"). innerHTML = "Nouveau contenu";
