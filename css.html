CSS : Cascading Style Sheets

CSS, pour Cascading Style Sheets (feuilles de style en cascade), est un langage utilisé pour définir l'apparence et la mise en page des éléments HTML. Il permet de contrôler la couleur, la taille, la disposition, l'alignement, et de nombreux autres aspects visuels de la page web.

La syntaxe de CSS

La syntaxe de CSS est composée de sélecteurs, de propriétés et de valeurs :

  • Sélecteur : Il désigne l'élément HTML auquel appliquer un style. Par exemple, p pour les paragraphes.
  • Propriétés : Ce sont les aspects que l'on souhaite modifier, tels que la couleur ou la taille. Exemple : color, font-size.
  • Valeurs : Elles définissent la valeur de la propriété, comme red pour la couleur ou 16px pour la taille de la police.

Structure d'une feuille CSS

Une règle CSS se compose de trois parties :

  • Le sélecteur : Il détermine à quel élément HTML la règle CSS sera appliquée.
  • Les accolades : Elles délimitent les déclarations de style.
  • Les déclarations : Elles contiennent des propriétés et leurs valeurs, séparées par deux-points.

Exemple :

p { color: red; font-size: 16px; }
