HTML : HyperText Markup Language

HTML, pour HyperText Markup Language, est un langage de balisage qui sert à structurer et afficher le contenu d'une page web. L'hypertexte permet de lier des pages entre elles, formant ainsi la célèbre "toile" du web. Grâce à ces liens, vous devenez un acteur actif du World Wide Web. Le HTML utilise des balises pour organiser le contenu : texte, images ou médias.

L'anatomie d'un élément HTML

Un élément HTML est constitué de plusieurs parties :

  • Balise d'ouverture : Elle délimite le début de l'élément. Elle est entourée de chevrons (<>) et contient le nom de l'élément.
  • Contenu : Le texte ou les éléments enfants qui se trouvent entre les balises.
  • Balise de fermeture : Elle marque la fin de l'élément, précédée d'une barre oblique (/).
  • Attributs (optionnels) : Placés dans la balise d'ouverture, ils ajoutent des informations supplémentaires à l'élément (comme class, id, ou src).

    • L'anatomie d'un document HTML

    Un document HTML est structuré en plusieurs sections essentielles :

  • Head : Contient des informations non visibles pour l'utilisateur, comme le titre de la page, les métadonnées, et les liens vers des fichiers externes (CSS, JavaScript).
  • Header : La section en haut de la page, souvent utilisée pour le logo, la navigation, et les titres principaux.
  • Body : C'est la partie visible de la page où se trouve tout le contenu (texte, images, vidéos, etc.).
  • Main : Contient le contenu principal de la page, souvent utilisé pour regrouper l'information la plus importante.
  • Footer : La section en bas de la page, généralement utilisée pour des informations supplémentaires comme les contacts, les mentions légales, ou les liens vers les réseaux sociaux.
