We Can Dev – Projet d’Apprentissage HTML/CSS
Ce projet est un exercice pédagogique réalisé dans le cadre d’un premier TD d’initiation au développement web. 
Il vise à mettre en pratique les bases du HTML et du CSS à travers la création d’un site fictif.

Objectifs :
- Apprendre à structurer une page web avec HTML5;
- Styliser des éléments avec CSS3;
- Mettre en place une navigation simple et responsive;
- Créer un formulaire de contact (sans traitement côté serveur).

Stack utilisée :
- HTML5;
- CSS3 (sans framework).

Remarques :
Ce site est fictif : la majorité des liens ne sont pas fonctionnels.

Le projet a été conçu pour l’apprentissage et non pour une mise en production.

Axes d’amélioration :
- Intégration d’un vrai backend pour le formulaire;
- Rendre les liens dynamiques et fonctionnels;
- Améliorer la structure CSS (modularisation, responsive avancé).
